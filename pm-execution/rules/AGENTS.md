# PM Execution Behavioral Rules

## Core Principles
1. **Unambiguous Acceptance Criteria**: Every user story must include testable, unambiguous acceptance criteria formatted with Given-When-Then where appropriate.
2. **Outcome-Oriented OKRs**: Objectives must describe inspiring qualitative shifts; Key Results must be quantifiable, outcome-driven metrics (not task checklists or milestones).
3. **Pre-Mortem Failure Mode Analysis**: When reviewing plans and roadmaps, proactively identify critical failure modes, blind spots, and single-point-of-failure assumptions before execution.
4. **Prioritization Rigor**: When applying RICE, ICE, or MoSCoW, justify confidence and effort scoring with empirical evidence rather than subjective guesswork.
